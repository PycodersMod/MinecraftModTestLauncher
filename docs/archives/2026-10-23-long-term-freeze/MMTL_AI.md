# MMTL 可选模型研究断点

日期：2026-10-23  
状态：`ARCHIVED_PAUSED`；本轮不开发模型。

## 产品边界

未来模型能力应是确定性 Launcher、Session 与 Agent 测试协议之外的可拔插辅助层，不能成为启动游戏或执行基本断言的依赖；不得以图像识别和鼠标模拟作为基础测试控制方案。

历史交接材料提到 Bug Analysis、Scenario Model/DSL、Action Catalog、结构化事件和日志分析等研究方向。当前没有依据把这些研究方向描述为已训练模型、生产推理服务或已验收功能。具体 RFC、数据 Schema、授权记录和样本覆盖率仍需从私有归档重新盘点。

## 安全与恢复条件

- 先冻结受控 API、场景 DSL、动作白名单、断言语义和人工授权边界。
- 原始世界、私有 Mod 源码、凭据及用户 Session 不得公开或作为未经授权的训练数据。
- 模型输出必须经过确定性策略校验；模型不得绕过 Session 身份、进程管理或安全停止机制。
- 用户明确解冻后，先恢复 RFC 与数据来源清单，再规划实现；本档案不授权自动恢复。
